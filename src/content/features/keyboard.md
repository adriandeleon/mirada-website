---
title: "Everything from the keyboard"
group: "Keyboard"
order: 2
summary: "Bare keys for looking, Ctrl for files and windows, the Mac's own keys where its keyboard differs, and a shortcuts window read from the same table the keys run on."
---

- **One table.** Every command has one name and one key, declared once, so the palette, the context menu, the Mac's menu bar and the shortcuts window cannot disagree.
- **Bare keys where there is nothing to type**: arrows, <kbd>+</kbd> <kbd>-</kbd> <kbd>0</kbd> <kbd>1</kbd>, <kbd>R</kbd>, <kbd>E</kbd>, <kbd>I</kbd>, <kbd>T</kbd>, <kbd>F</kbd>, <kbd>Z</kbd>.
- **The Mac's keys**: <kbd>⌘⌫</kbd> to trash, <kbd>Return</kbd> to rename, Preview's <kbd>⌘R</kbd> <kbd>⌘L</kbd> <kbd>⌘I</kbd> and <kbd>⌃⌘F</kbd>. <kbd>Backspace</kbd> alone steps back and never deletes.
- **Keyboard Shortcuts** (<kbd>Ctrl+?</kbd>) lists every key inside the app.

See the [Keybindings](/keybindings) reference.
