group: "The folder"

summary: "Type part of a file name and press Enter: the command palette, over the folder's images, with the current one under the cursor."
---

- **<kbd>Ctrl+P</kbd>** (<kbd>⌘P</kbd>) opens the palette over the folder's file names.
- **Loose matching.** Letters match in order, not necessarily together, so `0412` finds `IMG_20260412_0930.jpg`; ties stay in the folder's order.
- **Starts where you are.** The current image is selected, so the arrows move from there.
- **The same palette** as the commands, with the same keys inside it.

See [The folder](/docs/the-folder#go-to-image).
