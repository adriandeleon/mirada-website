summary: "Which folder and where in it, the size and format, the dates, and for a photo the camera, lens, exposure and location, with every metadata tag beneath."
---

- **The file and its place**: the folder (a click opens it in your file manager) and the position, such as 4 of 8.
- **The image**: size in pixels as you see it, format and file size; created and modified dates.
- **The camera card**: camera, lens, when it was taken, exposure, aperture, ISO, focal length, flash and location.
- **All Metadata**: every EXIF, maker-note, XMP and colour-profile tag the file carries, read by metadata-extractor.
- **Out of the way.** <kbd>I</kbd> (<kbd>⌘I</kbd> on a Mac) or the header's ⓘ button opens and closes it; Settings can open it at start.

See [Properties](/docs/properties).
