group: "Your desktop"

summary: "No account, no library, no telemetry, no network at all. A plain settings file you can read and edit, and files changed only when you ask."
---

- **Nothing sent anywhere.** Mirada makes no network requests: no telemetry, no crash reports, no update check.
- **No library.** No import and no database; the folder on disk is the truth.
- **Files changed only when you ask**: rename, trash, or an edit saved as a new file.
- **A plain settings file**, `settings.properties`, checked on read so a bad edit cannot break a start.
- **Free and open source**, MIT licensed, built in the open on GitHub.
