title: "Rename, trash, copy, drag, print"
group: "The folder"
order: 4
summary: "Work on the file without leaving the window: rename it, move it to the Trash (and back, on Linux), copy the picture and the file, drag it out, show it in the file manager, print it."
---

- **Rename** (<kbd>F2</kbd>, <kbd>Return</kbd> on a Mac): the name without its extension selected, and a name that is taken refused rather than overwritten.
- **Move to Trash** (<kbd>Delete</kbd>, <kbd>⌘⌫</kbd> on a Mac) and the next image shows. Never a permanent delete.
- **Undo Move to Trash** (<kbd>Ctrl+Z</kbd>) on Linux, up to twenty back, each to where it was.
- **Copy** (<kbd>Ctrl+C</kbd>) puts the picture, turned as shown, and the file on the clipboard: an app pastes the picture, a folder the file.
- **Drag out** a fitted image or a thumbnail into a chat, a mail or a folder.
- **Show in Folder**, Finder or File Explorer, with the image selected.
- **Print…** through the desktop's own print dialog, the image fitted to the page, turned as shown.
